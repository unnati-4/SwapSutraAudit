# SwapSutra API Contract Snapshot — Phase 5

Generated by static analysis of `appsscript.js` (137 unique `action` dispatch values across `doGet`/`doPost`), cross-referenced against `src/App.tsx`, `server.ts`, and `api/swapsutra.ts`.

**Reachability key:**
- `Frontend` — the exact action string appears in `src/App.tsx` (direct fetch call)
- `Proxy-only` — not found in App.tsx directly, but the action string appears in `server.ts` and/or `api/swapsutra.ts` (the Express/Vercel proxy layer that mediates real traffic) — genuinely reachable in production even without a literal match in App.tsx
- `No known caller` — not found in App.tsx, server.ts, or api/swapsutra.ts. Does NOT mean dead: many of these are still dispatched (see Method column) and listed in `listAvailableActions`, meaning they are externally callable via a direct POST/GET to the deployed Apps Script URL. See Phase 5 Section E for individual classification of the highest-risk ones.

**Admin column** — `Yes` means an `isAuthorizedAdminEmail`/`isAdminEmail` check was found within a few lines of the dispatch site. This is a heuristic (static proximity search), not a guarantee — always verify the actual handler body before relying on this for a security decision.
